## Required behavior
- Implement `speechcraft uninstall` in CLI plus discoverable --help. Provide `--yes` or `--force` for non-interactive ordinary uninstall and `--purge` (or --remove-data) only with explicit confirmation. For ordinary uninstall, interactive confirmation when TTY; in noninteractive require `--yes`. Clearly enumerate exact install command, app root, data preservation path(s) before irreversible actions.
- **Default uninstall deletes ONLY VERIFIED Speechcraft-owned application artifacts**: launcher wrapper (exact content or verified symlink), `app/current` when it points inside owned release directory, installed versioned release dirs with appropriate safeguards. Never remove all of ~/.local/bin, ~/.local/share, home, cwd, or arbitrary symlinks; don't blindly follow symlinks. Don't remove source checkout if `speechcraft uninstall` is invoked from a developer checkout or an unknown installation prefix. Fail closed on ownership/identity mismatches and show actionable errors. Do not silently leave a broken app/current if partial errors. Consider whether PATH block introduced by installer can be removed without touching user's custom edits; only remove if exact inserted marker and safe, otherwise leave it and report. Respect intentional separate data / XDG env; the optional purge should identify a strictly verified safe managed directory, never blindly follow environment supplied paths outside the owned tree, and avoid deleting custom paths or user projects without explicit verification/approval.
